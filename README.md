# MAFIA — Interactive Pitch

React + Vite pitch website, with the original 21st.dev Mesh Drift WebGL shader from the provided source, preserved in `src/ShaderBackground.tsx`.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. `npm run build` creates a production-ready `dist/` directory. Deploy the repository to Vercel with framework preset **Vite**.

The pitch includes 12 scrolling sections, including casting, content distribution, and edition-based sponsorship. Names, host, and commercial partners are proposals, not confirmed commitments.
